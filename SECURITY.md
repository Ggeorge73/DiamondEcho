# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: open the
repository's **Security** tab and choose **Report a vulnerability**. Do not
open a public issue, and do not include real visitor data in a report.

We aim to acknowledge reports within 3 business days.

## Scope

- https://diamondecho.com and https://www.diamondecho.com
- https://staff.diamondecho.com
- The DiamondEcho API on Cloud Run
- The code in this repository

Please do not run denial-of-service tests, automated scans that send heavy
traffic, social engineering, or tests that submit the public inquiry form with
real personal data.

How the site is monitored: [docs/security-operations.md](docs/security-operations.md).
